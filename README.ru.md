# **Bloodborne PC (Нативная версия для Linux) - Улучшенное издание**

Оптимизированная нативная сборка ПК-порта *Bloodborne* для Linux, включающая пользовательскую систему отслеживания достижений на C (runtime hook) и интерактивный графический лаунчер.

---

## **Возможности**
* **Нативная производительность Linux:** Запуск напрямую через Vulkan с оптимизированной плавностью кадров.
* **Кастомный хук достижений на C:** Перехватывает внутренние вызовы движка (`sceNpTrophyUnlockTrophy`) в `runtime_services.c` для точной фиксации трофеев и побед над боссами в реальном времени.
* **Сериализация JSON и синхронизация с UI:** Автоматически записывает разблокированные достижения в локальный файл `achievements.json`, который мгновенно обновляет трекер прогресса в лаунчере.
* **Поддержка FSR:** Встроенные варианты временного апскейлинга (FSR 3.1, FSR 4 и FSR 4.1.1) для высококачественного рендеринга на системах Linux.

## **Системные требования (Arch Linux)**
Перед сборкой проекта убедитесь, что установлены необходимые зависимости:
```bash
sudo pacman -S --needed base-devel cmake vulkan-headers glslang zydis xbyak miniz
```

## **Сборка и запуск**

    Клонируйте репозиторий:
    Bash

    git clone [https://github.com/pyL1nx/Bloodborne-PC-native-Enhanced-.git](https://github.com/pyL1nx/Bloodborne-PC-native-Enhanced-.git)
    cd Bloodborne-PC-native-Enhanced-

    Скомпилируйте движок:
    Bash

    bash build.sh

    Запустите игру и лаунчер:
    Bash

    bash launcher/bb-launcher.sh

## **Структура проекта**

    src/ — Модификации основного движка, включая пользовательский хук отслеживания достижений runtime_services.c.

    launcher/ — Python-лаунчер для отслеживания трофеев и настройки параметров игры.

    tests/ — Модульные тесты и верификация бэкенда для логирования достижений.
